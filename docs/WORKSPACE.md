# Workspace Layout

This repository keeps source and project documentation in version control, while generated firmware artifacts stay local.

## Tracked Project Files

- `main/`: ESP-IDF component source.
- `docs/`: architecture notes, register notes, roadmap, and workspace notes.
- `CMakeLists.txt`, `main/CMakeLists.txt`: ESP-IDF build definitions.
- `sdkconfig`: checked-in ESP32-C3 project configuration.
- `README.md`, `LICENSE`, `.clang-format`, `.gitattributes`, `.gitignore`.
- `Makefile`: optional wrapper for common ESP-IDF commands.

## Local-Only Files

- `build/`: generated by ESP-IDF.
- `sdkconfig.old`: generated when configuration changes.
- `.vscode/`: machine-local editor configuration.
- `.codex/` and `skills-lock.json`: local assistant/session metadata.

## Before Publishing

Initialize Git inside this directory, not at `C:/`:

```powershell
git init
git add .
git status
```

The status should show only project files, not Windows system folders.
